คู่มือเริ่มต้นใช้งาน (อ่านก่อนใช้ครั้งแรก)
  1. ระบบนี้คืออะไรจำลองบอยเลอร์ชีวมวล Champion CBD ทั้งระบบ ตั้งแต่เชื้อเพลิง เตา หม้อไอน้ำ economizer จนถึงปล่อง ทุกตัวเลขคำนวณจากสมดุลมวลน้ำ พลังงาน แรงดันอิ่มตัว และการเผาไหม้ ไม่ใช่ภาพเคลื่อนไหวเฉยๆ
  2. เริ่มต้นเลือกรุ่นที่มุมบน แล้วกด “เริ่มที่เดินเครื่องปกติ” (8 barg โหลด 70%) หรือ “เริ่มจากเครื่องเย็น” · ปุ่ม 1×–120× คือความเร็วเวลาจำลอง
  3. เดินเครื่องจากเย็นกด Start → ไล่ก๊าซ 60 วินาที → จุดไฟ → อุ่นเครื่อง (จำกัดการเผา 40% จนแรงดันถึง 3 barg) → เดินเครื่อง · จากนั้นเปิด “วาล์วไอน้ำหลัก” และตั้ง “ความต้องการไอน้ำของโรงงาน”
  4. ดูหน้าจอแถบตัวเลขด้านบนคือค่าหลัก · จอ 3D ลากหมุน/ซูมได้ มีปุ่มมุมกล้อง ผ่าดูภายใน และ “เส้นทาง” ไล่การไหลของเชื้อเพลิง ไอน้ำ และน้ำ · แผงขวาคือปุ่มควบคุม · ด้านล่างมีกราฟ 60 นาทีและรายการ Alarm (กด “รับทราบ Alarm”)
  5. ปรับค่าเองค่าตั้งแรงดัน · Auto/Manual การเผา · ค่าตั้ง O₂ · ตะกรับ (เวลาเดิน/หยุด) · ชนิดและความชื้นเชื้อเพลิง · พัดลม FD/ID เป็น Hz · ค่าตั้ง DP เตา · ปั๊มน้ำ
  6. ฝึกเหตุขัดข้องกดปุ่มในแผง “จำลองเหตุขัดข้อง” แล้วสังเกตค่าและ Alarm · เมื่อ Trip ให้แก้สาเหตุ (กดปุ่มเหตุนั้นอีกครั้ง) แล้วกด Reset → Start
  7. ข้อจำกัดค่าที่อิงโบรชัวร์ TPE: ประสิทธิภาพ 82%, ไอเสียออกหม้อ ~230°C, ออกปล่อง ~150°C · ค่าที่ยังประมาณ: ปริมาณน้ำในหม้อ มวลเหล็ก ขนาดพัดลม/ปั๊ม จังหวะตะกรับ · ถ้าเห็นค่าไหนไม่ตรงหน้างาน แจ้งในช่องความคิดเห็นด้านล่าง
